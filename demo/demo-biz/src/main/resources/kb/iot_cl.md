# iot_cl 表说明

## 数据含义

`iot_cl` 为实习演示用的 IoT 采集表，行按 `create_time` 递增。每条记录包含多列传感器或工况数值，可与 `demo` 服务的列名接口联用选择任意两列作为 Y 轴绘制双曲线。

## 使用建议

- 时间轴统一使用 `create_time`，与后端 `/demo/select`、`/demo/process` 对齐。
- 选择过短窗口可能导致统计特征不稳定，建议至少覆盖数十个采样点。

## 常见问答

当用户询问「两列差异大」时，应提醒：可能为量纲不同、标定零点不同或一列经过滤波窗口偏移（`num` 参数）导致相位差。
