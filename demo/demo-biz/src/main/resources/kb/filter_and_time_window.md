# 滑动平均滤波与时间窗口

## 算法说明

图表数据使用窗口大小为 3 的滑动平均滤波。实现上对整列先按 ID 序取片段再做平滑，因此**时间范围边界**处可能受窗口填充影响。

## 起始时间 00:00:00

业务上要求时间从 **2024-07-20 00:00:00** 起可选，最小单位为分钟。若起始时间恰为某日 **00:00:00**，滤波窗口在序列头部可能缺少前序点，易导致异常或错误；**建议从 00:01:00 或更晚一分钟起选**。

## num 参数

`/demo/process` 的 `num` 与第二列 Y 的滤波对齐有关（与第一列 `num=0` 对照）。调整 `num` 会改变有效数据切片起点，分析双曲线相关性时应明确告知用户该参数含义。
